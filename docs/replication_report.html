Replicação HAST-Python

Port para Python das Hoeffding Adaptive Splitting Trees (Nowak Assis, Barddal & Enembreck, DMKD 2026) e dos cinco ensembles do artigo, validado contra o código Java dos autores, e a comparação dos nossos resultados com as tabelas brutas do artigo. Os números abaixo são gerados pelos scripts do repositório e se completam à medida que as execuções terminam.

O que foi validado

  • Protocolo do artigo: EvaluatePrequential com avaliador cumulativo, 20 pontos, F1 macro do MOA com NaN contado como 0 e desvio populacional. ARF + HT no Outdoor dá acurácia 63,490 ± 1,229 (artigo: 63,487 ± 1,208).
  • Fluxo completo: ARTE + HLAST_D no Elec (45 mil instâncias, 100 membros) tem os 20 pontos idênticos entre Java e Python; F1 91,30 contra 91,33 no artigo.
  • Implementação rápida (numba) idêntica bit a bit à implementação de referência em Python nas 27 combinações testadas (Elec, Airlines, CovType).
  • A única diferença numérica é de 1 ulp em exp/log (intrínsecos da JVM), com erro relativo abaixo de 1e-15 nos votos.

Achados no código original

  • ARFHLAST descarta um atributo por folha (for j < numAttributes - 1); o ARFHoeffdingTree do MOA usa todos. Replicado; há opção para corrigir.
  • SRP do MOA não zera o learner de background ao promovê-lo; a árvore promovida é treinada duas vezes por instância até o próximo warning. Replicado.
  • ARF + HLAST/HLAST_D não reproduz o artigo no Outdoor (HLAST_D: acurácia 74,6 contra 67,6), embora ARF + HT reproduza. Python e Java concordam, então a diferença está na configuração ou versão usada pelos autores.
  • O F1 do MOA é instável em classes raríssimas. No Poker, a classe 9 tem 2 instâncias em 829 mil; se o ensemble nunca a prediz, o F1 fica indefinido (contado como 0) nos 20 pontos. Nosso F1 no Poker é 0, contra ~48 no artigo, com acurácia a menos de 1 ponto. O mesmo ocorre no Outdoor (classe 29). Por isso a comparação também usa a acurácia e a mediana das diferenças.
  • O ARTEAttributeClassObserver e o ARE não foram publicados e foram reconstruídos a partir dos artigos; o ARE é aproximado (ζ = 10 assumido).
